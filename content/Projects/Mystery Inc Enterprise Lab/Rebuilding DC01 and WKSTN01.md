## Context
During the first build of DC01 and WKSTN01, I completed much of the setup using PowerShell and command-line tools.

Although the environment worked, I realized I was relying on commands faster than I was understanding the underlying Windows administration concepts. I decided to remove both systems and rebuild them using the graphical management tools first.

## Objective

The goal of the rebuild is to get more comfortable with the Windows Server and Active Directory interfaces and understand where settings are located.

## Environment
See [[Architecture Overview]] for more detail.
- Systems involved: DC01, WKSTN01, OPNsense
- Network / segment: CORP — 10.10.10.0/24
- Tools: KVM/QEMU, libvirt, virsh, Windows Server graphical management tools
- Dependencies: OPNsense routing, CORP virtual network, existing VM backups
